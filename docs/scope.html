Blob Society: 20 mini worlds with few rules and big lessons

Primer uses simple blobs with two or three rules to show how evolution, game theory and markets work. This page scopes 20 simulations for one dashboard app. Each one has one question, a few knobs and one surprise that the viewer can see.

What makes a Primer simulation work (from 23 videos)
One questionEach video asks one thing, for example "Why does aging exist?"
2–3 rulesBlobs eat, copy themselves, or die. One payoff table or one rate drives the result.
Build up in stepsStart with 1 blob, then add a mutation or a rival. Each step adds one variable.
Sim and chart togetherThe arena shows single blobs. The chart shows the population. The viewer links both.
Theory checkThe sim result is compared to the formula: V/C, R₀, Hamilton's rule, equilibrium price.
Break it on purposeChange one knob until the result flips. This shows the true mechanism.

The 20 simulations

One dashboard, one engine

All 20 sims use one shell and one agent engine. Each sim is a small plug-in file with its rules, knobs, chart and theory line.

Engine (shared)

  • Agent = position, type, energy, age, genome (few numbers).
  • Day loop: move → meet → payoff → reproduce or die → mutate.
  • Two modes: well-mixed (random pairs) and spatial grid (neighbours).
  • Seeded random numbers, so a run can repeat exactly.
  • Optional ODE overlay for the theory curve (SIR, replicator, logistic).

Proposed build order

  2. Rest of game theory (#7–#10, #12) — they reuse the payoff-matrix module.
  3. Society and economy (#13, #15–#18).
  4. Evolution and inference (#1–#5, #20), then polish and phone layout.
